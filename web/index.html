FLUJO PASO A PASO

Guía de Conexión e Instalación

El orden exacto para vincular tu dispositivo Android, levantar el túnel de comunicación y habilitar el control por IA.

01

Conectar el Celular a la PC vía ADB

Activa la Depuración USB en Opciones de desarrollador de tu celular Android y conéctalo mediante cable USB o Wi-Fi.

CMD / Terminal PC
# 1. Comprobar que ADB detecta tu celular adb devices # (Opcional si usas Wi-Fi) Conectar vía depuración inalámbrica: adb connect 192.168.1.XX:5555
02

Copiar y Ejecutar el Servidor en Android (Root)

Transfiere el archivo binario compilado mem_server.sh a tu móvil, asígnale permisos completos y ejecútalo con Root.

MT Manager / ADB Shell
# Copiar binario a la memoria interna del teléfono: adb push android_server/libs/arm64-v8a/mem_server.sh /data/local/tmp/ # En MT Manager: Da permisos 777 (rwxrwxrwx) y dale a "Ejecutar" con Root # O mediante consola ADB Root: adb shell "su -c 'chmod 777 /data/local/tmp/mem_server.sh && /data/local/tmp/mem_server.sh'"
03

Iniciar el Cliente PC y el Túnel ADB Stealth

El cliente enciende el puente device_bridge.js, mapea el socket abstracto @memsvc y levanta el Dashboard Web en el puerto 3000.

PC Launcher
cd pc_client npm install start_client.bat # Abre automáticamente http://localhost:3000 con 13 pestañas interactivas
04

Vincular tu Inteligencia Artificial (MCP Server)

Añade la configuración en tu archivo mcp_config.json para que Antigravity IDE, Claude Desktop o Gemini tomen el control.

mcp_config.json
{ "mcpServers": { "linx-memory": { "command": "node", "args": [ "C:\\Users\\Usuario\\Documents\\C\\AB\\LINX_MCP_LECTOR\\pc_client\\server\\mcp_server.js" ] } } }
ARQUITECTURA DE VANGUARDIA

Capacidades del Ecosistema LINX

Creado específicamente para sortear protecciones modernas y habilitar automatización inteligente.

Evasión Stealth Total

No inyecta archivos .so ni manipula el código del ejecutable. La memoria es leída por llamadas del kernel directas desde un proceso externo independiente.

Socket Unix Abstract (@memsvc)

En lugar de abrir puertos TCP identificables en /proc/net/tcp, canaliza la comunicación por socket abstracto invisible para el anti-cheat del juego.

HUD Nativo Vulkan + ImGui

Renderiza cajas 2D/3D, esqueleto anatómico completo, radar y filtros de loot a 120 FPS sin ventanas flotantes Java ni sobrecargar la GPU.

Copiloto de IA vía MCP

Tu IA puede leer la partida en tiempo real, listar jugadores, calibrar offsets dinámicos de cámara y aplicar parches seguros con respaldo automático.

ELF Fixer para IDA Pro & Ghidra

Vuelca la librería libUE4.so desencriptada directamente desde la memoria RAM y reconstruye sus tablas de secciones corruptas.

Hot-Tuning en Tiempo Real

Modifica cualquier offset de cámara, actor o componente al vuelo sin reiniciar la partida ni recompilar el binario C++.
