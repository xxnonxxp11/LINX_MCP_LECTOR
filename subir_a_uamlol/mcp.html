CAPACIDADES

¿Qué hace único a LINX_MCP_LECTOR?

Diseñado para ser indetectable, ultra rápido y extensible por la comunidad.

🛡️

Evasión Stealth (Zero-Injection)

No inyecta librerías .so ni modifica el APK. La lectura de memoria se ejecuta mediante syscalls directas de forma totalmente externa.

🔒

Unix Abstract Socket (@memsvc)

No abre puertos TCP visibles en /proc/net/tcp. El socket de dominio Unix abstracto es invisible para los escaneos de red del anti-cheat.

🎨

Overlay Vulkan 1.1 + ImGui

Dibuja cajas 2D/3D, esqueletos anatómicos completos, líneas de visión, distancias y radar sin utilizar ventanas Java de Android.

🤖

Servidor MCP para Asistentes IA

Permite a modelos como Gemini o Claude conectarse como copilotos para inspeccionar memoria, volcar offsets y diagnosticar variables.

🔬

ELF Fixer para IDA / Ghidra

Vuelca librerías protegidas desde la memoria RAM y reconstruye sus cabeceras corruptas para análisis estático en desensambladores.

⚡

Hot-Tuning en Caliente

Ajusta matrices de cámara, offsets de actores y filtros de loot al instante sin necesidad de recompilar el binario C++.

GUÍA DE INICIO

Puesta en Marcha en 3 Pasos

Configura tu teléfono y computadora en menos de 5 minutos.

Paso 1

📱 Celular (Android Root)

Copia el binario a tu teléfono y asígnale permisos 777:

# 1. Copiar mem_server.sh a /data/local/tmp/ # 2. MT Manager: Permisos 777 (rwxrwxrwx) # 3. Tocar y pulsar "Ejecutar" (Root)
Paso 2

💻 Computadora (PC Client)

Inicia el puente y el dashboard con un solo comando:

cd pc_client npm install start_client.bat # Abre http://localhost:3000
Paso 3

🤖 Conectar IA (MCP)

Agrega la entrada en tu archivo mcp_config.json:

"linx-memory": { "command": "node", "args": [".../mcp_server.js"] }
