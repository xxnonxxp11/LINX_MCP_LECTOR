CAPACIDADES

Características Principales del Ecosistema

Diseñado para ser modular, indetectable y extensible por la comunidad.

🛡️

Evasión Stealth (Zero Injection)

No inyecta archivos .so ni modifica el binario del juego. La lectura de memoria se ejecuta mediante syscalls del kernel de forma externa y limpia.

🔒

Unix Abstract Socket (@memsvc)

En lugar de abrir puertos TCP abiertos detectables por el juego en /proc/net/tcp, utiliza un socket abstracto de dominio Unix canalizado por ADB.

🎨

Overlay Nativo Vulkan + ImGui

Dibuja cajas 2D/3D, esqueletos anatómicos, líneas de visión, distancias y radar a 120 FPS sin usar ventanas flotantes de Android ni capas Java.

🤖

Servidor MCP para Asistentes IA

Permite que inteligencias artificiales lean la memoria en vivo, ajusten matrices de cámara, diagnostiquen offsets y controlen el overlay en tiempo real.

🔬

ELF Fixer para IDA Pro y Ghidra

Vuelca librerías libUE4.so desencriptadas directamente desde la RAM y reconstruye sus cabeceras y tablas de secciones corruptas.

⚡

Hot-Tuning y Actualización en Vivo

Calibra offsets de UE4 al vuelo o actualiza el binario en el móvil sin necesidad de cerrar el juego ni desconectar la partida.

GUÍA DE INICIO

Puesta en Marcha en 3 Pasos

Configura tu teléfono Android Root y tu computadora en pocos minutos.

Paso 1

📱 Celular (Android Root)

Copia el archivo único a tu móvil y dale permisos completos:

# 1. Copiar binario a /data/local/tmp/
# 2. En MT Manager: Permisos 777
# 3. Tocar y pulsar "Ejecutar" (Root)
Paso 2

💻 Computadora (PC Client)

Inicia el servidor y el dashboard web con un solo clic:

cd pc_client
npm install
start_client.bat
# Abre http://localhost:3000
Paso 3

🤖 Conectar IA (MCP)

Agrega la entrada en tu archivo mcp_config.json:

"linx-memory": {
  "command": "node",
  "args": [".../mcp_server.js"]
}
